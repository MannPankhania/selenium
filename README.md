
# Selenium Automation Framework

## Project Description
This project is a Python-based Selenium WebDriver
automation framework developed for the
Recent Open-Source Lab (ROSL).

It automates browser interactions and verifies
web application functionality.

## Technologies Used
- Python
- Selenium WebDriver
- Google Chrome
- GitHub

## Features
- Automated browser launching
- Website navigation
- Finding webpage elements
- Automated form filling
- Button clicking
- Form submission validation
- Screenshot capturing
- Exception handling

## Project Structure
- screenshot.py - Selenium automation script
- requirements.txt - Required Python packages
- README.md - Project documentation

## Installation
Install the required dependencies:

    python -m pip install -r requirements.txt

## Execution
Run the automation script:

    python screenshot.py

## Expected Output
Website opened successfully
Test Passed: Form submitted successfully
Screenshot saved successfully
Browser closed

- Browser automation using Python
- Locating and interacting with HTML elements
- Automated test validation
